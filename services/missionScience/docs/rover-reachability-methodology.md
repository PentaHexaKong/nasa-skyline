# Bounded lunar rover reachability

## Scope and implementation

The independent `skyline_rover_science` package reuses the existing height-aware terrain, finite solar-disk and direct-Earth scientific evaluator. The optional process owns its cache and request gate. The rover package does not modify the orbital engine, the pinned INT-4 engine, the propagator or the existing scientific API implementations. This prototype serves the site-comparison extension associated with R4 and the proposed rover direction in ADR-0005.

Supported canonical catalog sites are CR1, GR1 and SR1. Each request preserves the catalog coordinate source. A frontend location with an unverified mapping receives an explicit unsupported result. Every candidate observer receives its actual derived coordinate and independent terrain horizon. There is no shared angular horizon offset.

## Terrain grid

The domain is a stationary 1 by 1 grid or a mobile 3 by 3 grid, centered exactly on the canonical site. Projected cell spacing is 80 to 320 m. The actual `LDEM_80S_80MPP_ADJ.TIF` inverse projection produces neighboring coordinates. The response records the DEM content hash, CRS WKT, affine pixel-corner transform, cell spacing and MOON_ME_DE421 frame. Columns increase projected X and rows decrease projected Y. Projected grid axes can differ from local east and north. Spacing describes projected coordinates, while edge distances use Moon-fixed Cartesian positions.

Ground elevations and slopes reuse the mission-science engine's real DEM bilinear sampler and 320 m slope footprint at 80 m terrain resolution. Cells lacking either elevation or slope support are invalid. A known cell above the requested slope limit is valid terrain with a false traversability mask. Missing terrain receives null reachability and arrival values. The search evaluates the known-terrain graph and cannot determine routes through unknown cells.

Each four-neighbor edge samples an actual DEM midpoint. Source, midpoint and destination slopes and both segment grades must satisfy the requested maximum slope. Surface Cartesian positions use the existing 1,737,400 m reference sphere plus measured DEM elevation. Distance is the sum of the two three-dimensional segments. Segment grades use radial height differences over reference-sphere arc length. No diagonal edges are created.

## Time-expanded evaluation

Nodes are cell and time-level pairs. Elapsed seconds use SPICE ET with UTC labels generated by SPICE. Duration must be an exact multiple of the requested 30 to 600 s step, with at most 120 intervals and a mission duration of 60 to 7,200 s. The endpoint is included as a possible arrival node.

For distance d, speed v and time step dt, traversal advances by `max(1, ceil(d / v / dt))` levels. Floating-point checks prevent snapping below the required distance. Edges longer than speed times the entire mission window are excluded before division. Every movement strictly advances time. Dynamic programming over increasing time levels computes all modeled arrivals and their earliest times.

Movement requires the requested Sun and communication conditions at source, midpoint and destination at every crossed time level, including arrival. This conservative envelope is explicit and remains sampled in space and time. Waiting advances exactly one level and requires the stopping conditions at both endpoints. Initial admission requires a traversable start and its stopping conditions at time zero. Arrival nodes use movement conditions, while an ensuing wait uses stopping conditions. Waiting can be disabled independently. Allowing dark or disconnected stopping is a stated model assumption.

Sunlight classification delegates to the existing requested any-disk, center or full-disk scientific rule. Direct communication delegates to Earth-center geometric terrain visibility. Observer height is meters above the sampled local terrain, from 0 to 20 m. Unrequested visibility is marked not_computed with null arrays. Such conditions are omitted from graph feasibility only when explicitly disabled by the request.

## Relay scope

Mobile relay evaluation is unsupported until each cell and edge midpoint has independently established observer and trajectory compatibility. A separate stationary one-cell comparison supports the existing verified canonical zero-height observer, aligned 120 s grid and compatible pinned January 2025 replay. The authoritative Go comparison exports one additional endpoint sample by evaluating a window extended by 120 s. The extra lookahead must remain within replay support.

Checks enforce matching site, observer position, frame, correction profile, actual sample grid, direct booleans, asset hashes and trajectory identity. Assisted availability requires simultaneous site-to-satellite and same-satellite-to-Earth availability, combined with direct visibility. Both stationary scenarios use the same exported clock and arrays. No trajectories are propagated or transformed by this package. Unsupported mobile relay retains a separately computed direct baseline and null assisted outputs.

## Bounds and identity

The request limits observer evaluations to 21, graph nodes to 1,089 and attempted transitions to 10,000. Default and maximum wall budget are 300 s. Wall checks are cooperative between complete scientific evaluations and graph layers, so a long individual geometry call can overrun the deadline. Exhaustion returns not_computed with null result, without presenting a partial graph as complete.

Private intermediate caches reuse the existing implementation- and asset-aware engine. Scenario identity includes the full request, grid, actual time grid, visibility sources, kernel and DEM hashes, core implementation hashes, rover implementation hashes and normalized compatible relay source. Creation timestamps and measured execution time are excluded. Different positions, heights, dates, scientific profiles or source identities cannot silently share a scenario identity.

## Metrics

`reachableMask` is existential reachability over the modeled time levels. `earliestArrivalS` is the earliest reachable level in elapsed ET seconds and `earliestArrivalUtc` is its actual SPICE UTC label. Unreached and unknown arrivals are null.

`reachedAtTimeMask` uses time-major, flattened row-major cell indexing. `reachableTimeLevelFraction` divides reachable levels by the full number of levels, including the endpoint. It represents discrete state coverage. `waitingOpportunityBinMask` has one fewer time row and identifies feasible waiting transitions on half-open sample bins. It carries no refined transition-time claim. `arrivalAtEndBoundaryMask` flags earliest arrivals at the final level. Relay differences include newly reachable cells and arrival-time gains only where both arrival times exist.
